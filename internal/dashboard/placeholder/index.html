The TaskForge dashboard has not been built

This binary was compiled before the dashboard's frontend was built, so it embeds this notice instead of the dashboard. It shows no data.

Run make dash-build from the repository root, then rebuild taskforge-api (make build) and start it again. The dashboard is embedded at compile time, so restarting the binary you already have is not enough. The build runs inside a pinned Node container; nothing beyond Docker is needed on this machine.
